Title: System Design: Rate Limiting Algorithms (Token Bucket and Leaky Bucket)

Rate limiting is a vital system design practice used to control network traffic volume, prevent abuse, and protect backend services from denial-of-service attacks or cascading failures. The Token Bucket algorithm allows bursty traffic by accumulating tokens up to a maximum capacity at a fixed rate, consuming tokens with each incoming request. The Leaky Bucket algorithm smooths out traffic spikes by queuing incoming requests and processing them at a constant, steady rate. Other approaches include Fixed Window and Sliding Window counters. Distributed rate limiting often coordinates state across multiple server nodes using fast atomic data stores, ensuring consistent enforcement of API quotas and service level agreements across large-scale distributed architectures.
